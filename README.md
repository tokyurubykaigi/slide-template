# TokyuRuby会議 スライドテンプレート

TokyuRuby会議で登壇される方向けのスライドテンプレートです。ご自由にお使いください。

## ファイル

- [TokyuRubyKaigi_template.key](./TokyuRubyKaigi_template.key)（Keynote）

## 使い方

1. 上のリンクからファイルを開き、「Download raw file」ボタンでダウンロードしてください
2. Keynote で開き、内容を書き換えてご利用ください

テンプレートの使用は必須ではありません。お好きなスライドで登壇いただいて構いません。

## 登壇にあたって

登壇者のみなさんも[TokyuRuby会議アンチハラスメントポリシー](https://github.com/tokyurubykaigi/policy)の対象です。スライドの内容もポリシーに沿ったものにしてください。
